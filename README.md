# GYM TRACKER
This application is a fitness tracking mobile application designed to help users manage and monitor their daily fitness activities. It provides features foruser authentication, profile management, BMI and calorie target calculation, nutrition tracking, and workout manegemenet

in general, the system follows this process:
User Input → Data Processing → Firebase Storage → Data Retrieval → Dashboard Display

\Through this workflow, the application combines personal information, nutrition records, daily steps, workout activities, and calculated fitness information into a single mobile fitness tracking system.\
